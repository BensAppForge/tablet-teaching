# Tablet Teaching – Project Specification

## Overview

**Tablet Teaching** is a web app (PWA/SPA) for teachers—primarily foreign language educators—to create, distribute, and evaluate quizzes both digitally and in print. The app prioritizes privacy (especially for use in Germany), CEFR-aligned content, and engaging, responsive design for both teacher and student users.

## 1. Core Features

### 1.1 Teacher Features

- Account creation via email/password or social login (Google, Microsoft).
- Dashboard for creating, editing, cloning, deleting, distributing, and evaluating tests.
- Manual and AI-assisted test creation.
- Test distribution via QR code or short alphanumeric code.
- PDF export of quizzes in A4 format, optimized for printing and handwriting.
- Quiz configuration options:
  - Target language
  - CEFR level
  - Topic
  - Description
  - Default time per question (5–30 seconds)
  - Default credit points
  - Multiplier per question (steps of 0.5)
- Leaderboard view with CSV export and manual deletion of student attempts.

### 1.2 Student Features

- Access via code and nickname (no login required).
- Responsive quiz interface for mobile and tablets.
- Two quiz modes:
  - **Live**: Teacher starts each question synchronously.
  - **Individual**: Students complete quizzes on their own.
- Nickname must be unique per quiz.
- Warning to remember code and nickname.
- Leaderboard view after test (even after expiration).
- Privacy disclaimer shown before quiz, with "don't show again" option.
- Retakes allowed or blocked based on teacher setting.
- Expired quiz codes trigger a read-only leaderboard view.

### 1.3 Premium Features ✓

- Tiered access model with basic and premium tiers ✓
- Features accessible to all users, with restrictions for basic users: ✓
  - Test creation (Basic: limit of 3 tests, Premium: unlimited) ✓
  - AI-generated tests (Basic: 1 per month, Premium: unlimited) ✓
  - PDF export (Basic: with watermark, Premium: without watermark) ✓
  - Statistics (Basic: simple stats, Premium: advanced analytics) ✓
- Premium subscription options: ✓
  - Monthly: 9,99 € ✓

- Beta tester status for early access to premium features ✓
- User profile showing premium status with badge icon ✓

## 2. Test Types

Supported quiz formats:

- Multiple Choice (2–4 options)
- True/False
- Gap-Fill (with distractors)
- Matching (left-right items)
- Reordering:
  - Horizontal (sentence building)
  - Vertical (verb conjugation steps)

Each task has structured JSON output and can be edited manually or generated by AI.

## 3. AI Assistant

- Teachers must enter a prompt ("AI instructions").
- Backend uses system prompts and function calling (e.g., OpenAI API) to generate structured test data in JSON.
- Inputs include:
  - General settings
  - File upload (PDF, DOCX, plain text)
  - Pasted text
  - Task type preferences
  - Number of questions to generate
- Teachers can preview, edit, and regenerate questions.

## 4. Database Schema (Firebase Firestore)

Collections:

- `teachers`: Auth-linked accounts with metadata, premium status flags, and subscription data ✓
- `tests`: Test metadata, linked to teacher ✓
  - Contains fields for title, description, language, CEFR level, time settings, and timestamps ✓
  - Questions maintained in subcollections with explicit ordering ✓
- `questions`: Stored as subcollections under tests ✓
  - Each question has a type, content fields, and explicit ordering mechanism ✓
  - Question order maintained across edits and deletions ✓
- `distributions`: Test delivery metadata (code, QR, expiration, mode)
- `attempts`: Nickname + score + answers (per quiz attempt)

Leaderboard is computed from attempts, not stored separately.

## 5. Quiz Mechanics

- One question per screen.
- Timer per question (configurable).
- Immediate feedback after each question (correct/wrong with explanation).
- Confetti and sound effects (toggleable).
- Customizable confetti (default or emoji-based).
- Fullscreen mode for quizzes.

## 10. UI & User Flow (Teacher)

### 10.1 Landing Page

The landing page displays two large cards:

- "Ich bin Lehrkraft"
- "Ich bin Schüler\*in"

A slogan such as "Sprachenlernen testen. Einfach. Digital. Sicher." is shown. The page is fully responsive and contains no music or autoplay media. Selecting an option navigates the user to the appropriate flow.

### 10.2 Teacher Flow

After selecting "Ich bin Lehrkraft":

- Redirect to login/signup view. ✓
- After login: optional onboarding flow (one-time walkthrough).
- Then route to the main teacher dashboard. ✓

### 10.3 Teacher Dashboard

Card-based design using shadcn/ui and Tailwind CSS. Dashboard includes: ✓

- **Meine Tests**: list of saved tests with actions (edit, clone, delete, distribute, leaderboard). ✓
- **Neuer Test**: create new test, either manually or with AI. ✓
- **Premium-Funktionen**: overview of premium status and features. ✓
- **Hilfe** ✓
- **Einstellungen**: profile, premium options, preferences. ✓
- **Impressum**, **Datenschutz** ✓

### 10.4 Test Creation Flow

**Manual Creation**: ✓

- Step-by-step form for general settings and question entry. ✓
- Dynamic form components per task type. ✓
- Override defaults per question. ✓
- Question reordering with drag-and-drop interface. ✓

**Test Editing**: ✓

- Edit existing test metadata and questions ✓
- Add, remove, or reorder questions ✓
- Consistent ordering preservation ✓

**AI Creation**:

- General settings input.
- Upload/paste source text (optional).
- Enter prompt (required).
- Select task types and quantity.
- Call OpenAI API.
- Review and edit output.

### 10.5 Test Distribution

- Generates code and QR code.
- Choose live or individual mode.
- Set expiration date.
- Options: allow retakes, show leaderboard.

### 10.6 Leaderboard View

- View nickname and score.
- Export as CSV.
- Manually delete results.

### 10.7 Premium Features Page ✓

- Features tab showing detailed comparison between basic and premium features ✓
- Pricing tab with monthly and yearly subscription options ✓
- FAQ tab with common questions about premium features ✓
- Status card showing current subscription status and expiration date (if applicable) ✓
- Back button to return to dashboard ✓
